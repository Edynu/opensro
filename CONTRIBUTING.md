# Contributing to OpenSRO

Thanks for helping rebuild Silkroad Online!

1. **Set up:** follow [docs/GETTING_STARTED.md](docs/GETTING_STARTED.md). You need your own licensed v1.150 client for the asset build.
2. **Read the rules:** [AGENTS.md](AGENTS.md) applies to humans and AI coding agents alike. All code follows the id Software (Quake III) style.
3. **Before a pull request:** run the checks for what you touched. `pnpm check source` needs no game data.
4. **Find something to do:** issues labelled [good first issue](https://github.com/opensro-dev/opensro/labels/good%20first%20issue).

Questions? Ask in #🛠️contributing on our [Discord](https://discord.gg/RUua9HY657).
